PROJECT TITLE:
Dynamic Personal Portfolio with Admin Dashboard

SHORT DESCRIPTION:
A full-stack MERN (MongoDB, Express, React, Node.js) portfolio website featuring a secure Admin Dashboard for real-time content management. Built to showcase projects and skills dynamically without code changes.

FULL DESCRIPTION / KEY FEATURES:

🚀 Overview
Developed a comprehensive personal portfolio application that allows for dynamic content updates through a custom-built Content Management System (CMS). This project bridges the gap between a static showcase and a dynamic application, providing full control over the displayed data.

✨ Key Features
- **Dynamic Content Management:** Update projects, skills, profile information, and contact details directly from the Admin Dashboard.
- **Secure Authentication:** Protected admin routes with login functionality to ensure only authorized access.
- **Cloudinary Integration:** Seamless image uploading for profile pictures and project thumbnails, optimized for performance.
- **Responsive Design:** Fully responsive UI built with React and modern CSS variables, ensuring a great experience on all devices.
- **Real-time Updates:** Changes made in the dashboard are instantly reflected on the public-facing site.
- **Modern Tech Stack:** Utilized the MERN stack for robust performance and scalability.

🛠️ Technologies Used
- **Frontend:** React.js, Vite, React Router, Lucide Icons
- **Backend:** Node.js, Express.js
- **Database:** MongoDB (with Mongoose ODM)
- **Cloud/Services:** Cloudinary (Image Storage), Vercel (Frontend Hosting), Azure (Backend Hosting)
- **State Management:** React Context API
